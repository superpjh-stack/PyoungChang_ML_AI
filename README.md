# 평창꽃순이김치 머신러닝 AI

김치 생산 LOT의 배합·절임·숙성·저장 조건으로 관능 품질점수를 예측하고, 목표 품질과 원재료비 제약 안에서 후보 배합/공정을 추천하는 제조 의사결정 지원 프로토타입입니다. 고려솔더 ML 서비스에 사용한 제조 ML 설계 방식(모델 비교, 제약 최적화, 품질 예측, LOT 추적)을 김치 공정에 맞게 적용했습니다.

> 현재 데이터, 품질 경계, 원가와 모델 성능은 모두 재현 가능한 **데모 값**입니다. 출하 판정이나 설비 자동제어에 사용할 수 없으며 실제 적용 전 평창꽃순이김치의 승인 배합표, 원료 규격, 검사법, 원가와 LOT 이력으로 교체해야 합니다.

## 실행

```bash
source .venv/bin/activate
uvicorn api.main:app --reload --port 8011
```

별도 터미널에서 `cd web && npm run dev`를 실행합니다. 테스트는 `.venv/bin/pytest`, 프런트엔드 빌드는 `cd web && npm run build`입니다.
